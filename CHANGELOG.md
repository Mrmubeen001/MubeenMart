# Changelog

All notable changes to the MubeenMart project are documented in this file.

- **v1.1.0** (2026-10-10): Integrated AI Chatbot assistant with Gemini/Mock providers, rate limiting, and in-memory session caching.
- **v1.0.0** (2026-09-21): Full build release with completed F1-F8 features, verified review engine, security hardening, and test coverage.
- **v0.2.0** (2026-08-23): Added seller sales performance dashboard, order status transitions (O2), and administrator listing moderation.
- **v0.1.0** (2026-08-10): Minimum Viable Product (MVP) delivering user authentication, product catalog browsing, cart, and mock checkout.
